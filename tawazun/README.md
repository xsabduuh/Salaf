# تطبيق توازن

تطبيق عربي متكامل للهاتف يجمع الميزانية الشهرية، تتبع العادات، تمارين Push-up ومؤقت تمارين كيجل. يعمل دون حساب ويحفظ البيانات محلياً في المتصفح.

## النشر على GitHub Pages

1. فك ضغط الملف.
2. ارفع **كل الملفات والمجلدات كما هي** إلى مستودع GitHub جديد.
3. من المستودع افتح: `Settings` ← `Pages`.
4. في `Build and deployment` اختر `Deploy from a branch`، ثم فرع `main` والمجلد `/root` واضغط `Save`.
5. بعد ظهور رابط الموقع افتحه من الهاتف.

## إضافته إلى الشاشة الرئيسية

- **iPhone / Safari:** زر المشاركة ← إضافة إلى الشاشة الرئيسية.
- **Android / Chrome:** القائمة ← تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.

## ملاحظات

- لا تحذف مجلد `assets` أو ملف `manifest.webmanifest` لأنهما مسؤولان عن أيقونة التطبيق والتثبيت.
- البيانات محفوظة على نفس المتصفح والجهاز. حذف بيانات الموقع أو المتصفح يحذف السجلات.
- PIN داخل هذا التطبيق قفل محلي للخصوصية اليومية، وليس تشفيراً للبيانات.
- تمارين كيجل في التطبيق للتنظيم فقط. توقف عند الألم واستشر مختصاً عند وجود مشكلة صحية.

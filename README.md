# Salaf — تطبيقاتي

مجموعة تطبيقات ويب خفيفة (HTML/CSS/JS) تعمل مباشرة في المتصفح:

| التطبيق | المجلد | الوصف |
|---|---|---|
| صفاء | `index.html` (الجذر) | متتبع العادات والتعافي |
| ميزاني | `mizani/` | مدير الميزانية الشهرية |
| توازن | `tawazun/` | التطبيق الشامل: ميزانية + عادات + تمارين |
| لعبة XO | `xo-game/` | لعبة إكس أو ضد صديق أو بوت |

كل تطبيق يعمل بفتح ملف `index.html` الخاص به في المتصفح، بدون خادم.
